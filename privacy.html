마음 서랍 개인정보처리방침

시행일: 2026년 10월 23일

1. 수집하는 개인정보

운영자는 이용자가 작성한 일기·감정 기록·사진·영상을 수집하거나 운영자 서버에 저장하지 않습니다. 회원가입, 로그인, 이름·이메일·전화번호 입력이 없으며, 일기 내용이나 사진·영상을 운영자의 서버로 보내지 않습니다. 단, 이용자가 이야기 나눔터에 직접 올린 글은 아래 7번에 따라 처리됩니다.

2. 일기가 저장되는 곳

이용자가 쓴 일기, 고른 감정 단어, 사진·영상은 모두 이용자 기기의 브라우저(또는 앱) 저장 공간에만 저장됩니다. 저장할 때는 이용자가 정한 비밀번호로 암호화(AES-256)되며, 내용을 읽으려면 비밀번호가 필요합니다. 단, 기기 감염·취약한 비밀번호·잠금 해제 상태의 기기 접근 등 모든 위험을 막는 것은 아닙니다.

3. 비밀번호

앱 코드는 비밀번호 자체를 저장하거나 외부로 전송하지 않습니다. 브라우저의 비밀번호 저장 기능은 이용자의 설정에 따릅니다. 따라서 비밀번호를 잊어버리면 운영자도 일기를 복구해 드릴 수 없습니다.

4. 백업 코드

'보관' 메뉴의 백업 코드와 백업 파일은 암호화된 데이터이며, 이용자가 직접 복사해 보관합니다. 운영자는 백업 코드를 받거나 보관하지 않습니다.

5. 접속정보와 외부 서비스

이 버전은 외부 폰트 서비스, 광고 및 외부 방문 분석 도구를 사용하지 않습니다. 자체 방문 집계는 아래 방문 통계 항목을 참고하세요. 서비스 화면과 파일을 제공하는 호스팅 사업자(Vercel 또는 GitHub)는 서비스 제공·보안 등을 위해 IP 주소와 요청 정보 등을 처리할 수 있습니다. 이는 일기 내용의 전송과는 구별됩니다.

호스팅 사업자의 처리에 관해서는 Vercel 개인정보 정책 및 GitHub 개인정보 정책을 참고하세요.

2026년 10월 23일 확인한 Vercel 요금제는 Hobby이며, 공식 문서의 대시보드 런타임 로그 보관 범위는 1시간입니다. 보안·CDN·빌드 등 사업자의 모든 운영 기록이 1시간 뒤 삭제된다는 뜻은 아닙니다. 별도 운영 기록은 해당 사업자 정책에 따릅니다.

6. 데이터 삭제

잠금 화면의 '비밀번호를 잊었어요 → 기록 모두 지우기'를 이용하거나, 브라우저의 사이트 데이터를 삭제하면 해당 사이트의 브라우저 저장소에 있는 일기와 사진·영상이 삭제됩니다. 직접 내려받거나 공유한 백업 파일·코드, 다른 기기나 다른 사이트 주소의 기록은 별도로 삭제해야 합니다.

7. 이야기 나눔터(후기·게시판)

이야기 나눔터는 일기장과 별개인 공개 게시판입니다. 이용자가 직접 올린 닉네임, 제목, 글·댓글 내용, 작성 시각은 기존 게시물 보관과 신고·삭제 처리를 위해 저장되며, 기존 공개 글은 읽기 전용 보관함에서 누구나 볼 수 있습니다. 현재 새 공개 글·댓글을 받지 않습니다. 자동 필터는 금칙어·연락처·광고 등 정해진 규칙을 검사하며, 외부 AI 서비스에 글을 보내지 않습니다. 신고되거나 이용 원칙을 위반한 글은 숨김·삭제될 수 있습니다. 회원가입이나 연락처는 받지 않습니다.

도배 방지와 이용 제한을 위해 접속 IP 주소는 저장하지 않고, 비밀값을 결합해 해시로 바꾼 가명 식별값만 저장합니다. 기존 글에 연결된 값은 운영자가 글을 삭제할 때까지 보관합니다. 반려·숨김만으로 원본이 삭제되지는 않습니다. 글쓰기 제한값은 180일, 중복 신고 구분값은 30일 후 자동 만료합니다. 글에 연결된 신고 사유·횟수는 글 삭제 시 함께 삭제합니다. 자동 필터로 모든 개인정보나 권리 침해를 확인할 수는 없습니다.

게시판·비공개 의견·방문 통계 서버는 Vercel(미국)과 Upstash 서비스를 사용합니다. 2026년 10월 23일 설정 확인 기준 Upstash 기본 저장 리전은 미국 동부(iad1)입니다. 해당 기능 이용 시 필요한 항목을 인터넷으로 전송합니다. 게시글·의견을 제출하지 않으면 그 내용은 전송되지 않으며, 방문 통계와 호스팅 요청 정보 처리는 아래와 같습니다. 저장 리전이 호스팅·사업자 운영 기록 전체의 처리 위치를 의미하지는 않습니다.

올린 글을 지우고 싶으면 아래 문의 이메일로 글 번호(보관함에 표시) 또는 접수번호와 작성 시각을 알려 주세요. 확인 후 운영자가 삭제합니다. 비밀번호·일기 원문을 문의에 첨부하지 마세요. 글에는 이름·연락처·학교·회사 등 나를 알아볼 수 있는 정보를 쓰지 말아 주세요.

비공개 개선 의견

의견 화면에서 이용자가 직접 쓴 의견(5~1,000자), 접수번호, 접수 시각, 처리 상태를 Vercel·Upstash 서버에 보관합니다. 일기·감정·사진·비밀번호를 자동 첨부하지 않으며 닉네임·연락처를 요구하지 않습니다. 운영자만 볼 수 있고 공개·광고·외부 AI 학습에 사용하지 않습니다. 사용성 개선을 위한 참고용이며 개별 답변·반영을 약속하지 않습니다.

만 14세 이상임을 확인하고 목적·항목·보관기간에 동의한 경우에만 접수합니다. 선택 사항이며 참여하지 않아도 일기 기능을 쓸 수 있습니다. 의견 원본은 접수 후 최대 90일 후 자동 만료합니다. 접수번호·접수 시각으로 된 목록 색인은 다음 의견 접수 때 90일이 지난 항목을 정리합니다. 도배 방지용 IP 해시 요청 횟수는 24시간, 하루 전체 건수는 2일 후 자동 만료합니다. 삭제·열람 요청은 접수번호를 문의 이메일로 알려 주세요. 공개됐던 과거 글의 외부 복사본·검색 캐시는 회수하기 어려울 수 있습니다.

방문 통계

일기장 화면의 오늘·누적 방문 수를 제공하기 위해 숫자 합계만 Vercel·Upstash 서버에서 집계합니다. 통계 요청에는 일기·감정·첨부파일·비밀번호·닉네임을 포함하지 않으며, 통계 기능은 IP 주소·기기 지문·방문자 식별자를 저장하지 않습니다. 호스팅 사업자의 접속 로그 처리는 위 5번과 같습니다.

브라우저의 로컬 저장소에는 마지막 집계 날짜와 집계 제외 설정만 저장하며 서버로 보내지 않습니다. 같은 브라우저·사이트 주소에서 한국 시간 기준 하루 1회 집계를 시도합니다. 누적 수는 집계 시작일부터 일별 방문 수를 합한 값으로, 실제 이용자 수가 아니며 다른 기기·브라우저·주소, 저장소 삭제, 자동 접속이나 통신 오류로 중복·누락될 수 있습니다.

날짜별 숫자는 최대 90일, 누적 숫자와 집계 시작일은 통계 제공 기간 동안 보관합니다. 일기장 하단의 '집계 기준'에서 이후 방문 집계를 제외할 수 있습니다. 제외 설정 전 집계한 숫자에는 개인 식별 정보가 없어 특정인의 방문만 찾아 삭제할 수 없습니다. 브라우저의 사이트 데이터를 삭제하면 제외 설정도 초기화되므로 다시 선택해야 합니다.

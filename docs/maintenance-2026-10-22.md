# 최소 운영 전환·점검 기록

- 사용자 선택: 공지·비공개 개선 의견·숫자 통계만 신규 운영. api/posts 공개 작성·댓글 거부. 기존 글은 읽기 보관함, 제목 펼침·5개 글·번호5개 묶음. API 20개 배치를 필요한 만큼 불러오며 건수는 불러온 공개 글 범위로 표시. 전체 미조회 시 `이상` 표시.
- 비공개 의견은 일기 자동 첨부 없음, 별도 동의·만14세 확인·권리 확인·1,000자 제한. Redis 원본90일 TTL, IP 해시 요청횟수24시간 TTL, 일전체30건·IP구분당3건/일. 관리자 공개승인 금지, 검토완료/삭제만. 기존 공개글 삭제권은 이메일/신고 유지.
- 서버 개인정보 필터 NFKC/제로폭 제거 후 검사·일반번호/SNS핸들/일부주소 감지 추가, 기존 글 조회도 필터 재검사. 모든 실명/맥락·저작권 침해를 자동 확인할 수 없음.
- 처리방침: 반려·숨김은 삭제가 아님, 원본 삭제 시점/신고 구분 TTL 구별. 확인되지 않은 Upstash 리전 단정 제거(실제 리전·계약 확인은 운영자가 필요). 비공개 의견 새 처리 반영.
- 고운바탕/돋움 원본 OFL/출처 파일 포함, 로컬 WOFF2 사용. 외부 폰트·캐릭터 수집 안 함. 외부 서비스: Vercel·Upstash 호스팅/저장, GitHub Pages는 정적 배포. 일기 본문/미디어·암호는 서버로 보내지 않음.
- 상단 사이트 메뉴·접힌 안내/꾸미기, 동물5종 크기/자세/동작 구분. 기존 암호화/백업 포맷 유지. 시스템 동작줄이기와 정지 선택 지원. SW 캐시 v10.
- 법적 무위험/규정 준수 완료 보장 금지. 외부 인프라 로그 보관·리전·국외이전 상세 계약조건은 운영자 확인이 필요하다.
